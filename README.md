# LinkedIn Viewed Capture

Captures the who-viewed list before LinkedIn truncates it, paging and deduping into an exportable table.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/li-viewed-capture-userscript/raw/main/li-viewed-capture-userscript.user.js
```

## Usage

Open the profile-views page, press the 👁 chip (Alt+V), Capture, then export.

## Limits

- Free tier only shows a recent slice; older viewers are behind premium
- Virtualised list, so scrolling is required
- Names come from whatever the card renders

## Risk

Gray: read-only harvest of your own data.
